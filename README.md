# Varbase AI Default

A recipe to configure default AI modules, settings, and permissions in Varbase, enabling OpenAI integrations for alt-text generation, CKEditor enhancements, and various AI-powered features.

## Documentation

Read the [Varbase AI documentation](https://docs.varbase.vardot.com/developers/understanding-varbase/varbase-ai-recipes) on the Varbase docs site.

## Installation

Add the recipe using composer:
```
composer require drupal/varbase_ai_default:~1
```

Change directory to `/web` or `/docroot`

Run the Drupal recipe bash script:
```
bash core/scripts/drupal recipe recipes/contrib/varbase_ai_default
```

or 

Run the Drush recipe command:
```
drush recipe recipes/contrib/varbase_ai_default
```
